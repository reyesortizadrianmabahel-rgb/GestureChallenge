¿Cómo se relaciona el aprendizaje con el juego?

El modo de reflejos detecta gestos genéricos. No califica señas auténticas de LSM. Para incorporar retos de LSM verificados necesitaremos referencias visuales fiables y un modelo entrenado para esas señas.
